# Iris Flower Classification 🌸

## Project Overview

This project is an end-to-end Machine Learning classification project using the famous Iris dataset.

The objective is to predict the species of an Iris flower based on its physical measurements:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The model classifies flowers into three species:

* Setosa
* Versicolor
* Virginica

---

## Machine Learning Workflow

The project follows a complete Machine Learning pipeline:

1. Load the Iris dataset
2. Perform Exploratory Data Analysis (EDA)
3. Check data types and missing values
4. Analyze descriptive statistics
5. Visualize the dataset using pair plots and box plots
6. Analyze feature correlations
7. Identify important features
8. Split the dataset into training and testing sets
9. Train multiple Machine Learning models
10. Evaluate and compare model performance
11. Select the best-performing model

---

## Models Used

The following Machine Learning algorithms were trained and compared:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* Random Forest Classifier

## Key Insights

* The dataset contains 150 samples.
* There are three balanced classes with 50 samples each.
* The dataset contains no missing values.
* Petal length and petal width are the most important features for distinguishing between Iris species.
* Multiple Machine Learning models were compared to identify the best-performing classifier.
